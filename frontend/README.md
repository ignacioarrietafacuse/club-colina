# Club Colina

Quiero construir un DEMO PREMIUM completamente visual de una plataforma SaaS llamada "Club Colina".

IMPORTANTE:

Este NO es el producto final.

Este NO necesita backend.

NO necesita Supabase.

NO necesita autenticación.

NO necesita base de datos.

NO necesita APIs.

NO necesita lógica real.

Todo debe funcionar utilizando datos simulados (mock data).

El objetivo de este demo es mostrar la visión completa del producto al directorio de Club Basketball Colina y Club Voleibol Colina para validar funcionalidades antes de comenzar el desarrollo.

NO quiero una landing page.

NO quiero un MVP simple.

Quiero un software que parezca un producto terminado utilizado por cientos de clubes deportivos.

Debe sentirse al nivel de:

• Linear

• Notion

• Stripe

• Vercel

• Attio

La experiencia debe ser extremadamente premium.
