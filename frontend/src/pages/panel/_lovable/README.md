# Pantallas originales de Lovable (solo referencia)

Copia de las pantallas del panel tal como venían de `cc-frontend`, con sus datos de
ejemplo (`mock-data.ts`). **No están conectadas al router, no se compilan ni se
publican**: están excluidas de `tsconfig.json` y del lint.

Sirven de referencia visual para la sesión S4 de la Ola 1, que las borra completas
(junto con `mock-data.ts`) cuando termina el panel real. Nada de este directorio se
importa desde otro lugar.
